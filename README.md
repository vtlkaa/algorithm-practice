# Algorithm Practice

Репозиторий для подготовки к алгоритмическим собеседованиям и стажировкам.

Здесь я решаю задачи на Python с LeetCode, Codeforces и других платформ, изучаю алгоритмы и структуры данных, разбираю ошибки и отслеживаю свой прогресс.

## Цели

- Научиться решать алгоритмические задачи самостоятельно.
- Изучить основные алгоритмы и структуры данных.
- Анализировать временную и пространственную сложность.
- Подготовиться к техническим собеседованиям на Python Backend.
