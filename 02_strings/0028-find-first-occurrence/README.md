## Условие

Даны две строки: `haystack` и `needle`.

Нужно найти индекс первого вхождения строки `needle` в строку `haystack`.

Если вхождение не найдено, необходимо вернуть `-1`.

В этой тренировке нельзя использовать готовые методы поиска подстроки, такие как `find()` и `index()`.

## Примеры

**Пример 1**

```python
haystack = "hello"
needle = "ll"
# Результат: 2
```

**Пример 2**

```python
haystack = "aaaaa"
needle = "bba"
# Результат: -1
```

## Идея решения

Последовательно проверять фрагменты строки `haystack`, начиная с разных индексов. Длина каждого проверяемого фрагмента должна совпадать с длиной `needle`.

Если фрагмент совпал с `needle`, вернуть его начальный индекс. Если совпадений нет, вернуть `-1`.
